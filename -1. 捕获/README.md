## 使用说明

**快记**（快捷键 Ctrl+Shift+N，或命令面板搜"快记"）
  - 弹出输入框起标题 → 在 `-1. 捕获/` 中新建一篇带模板的笔记
  - 适合：需要详细记录的想法、文章片段

**随手记**（快捷键 Ctrl+Shift+M，或命令面板搜"随手记"）
  - 弹出单行输入框 → 自动追加到本文件夹的 `随手记.md`
  - 适合：零碎提醒、临时思路、待办事项

## 清箱流程

1. 打开 **[[6-主页/Home|Home 首页]]** 查看最近捕获的内容
2. 逐条处理 `-1. 捕获/` 中的笔记，判断归属：
   - **有明确目标的项目** → `1. 项目/` 
   - **长期负责的领域** → `2. 领域/`
   - **感兴趣的主题** → `3. 资源/`
   - **已完成/不再跟进** → `4. 存档/`
   - **要对外输出** → `5. 表达/`
3. 顺手更新对应的 **MOC**（内容地图）
4. 处理完随手记行 → 也分解到对应位置

> 建议每周清一次收集箱，保持流动。
