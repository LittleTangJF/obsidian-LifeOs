### **首屏渲染（白屏优化）**

**网络层面**、**资源层面**、**浏览器渲染层面** 和 **服务端层面** 四个维度来进行优化。
**一.网络层面**
 - ==CDN   内容分发网络==
	 - 将将你的静态资源（JS、CSS、图片、字体）部署到CDN 节点上用户访问时，可以从地理位置上最近的节点获取资源，极大减少网络延迟
 - ==dns-prefetch预解析==
	 - 浏览器提前进行 DNS 查询
 - ==HTTP/2 或 HTTP/3==
	 - 支持多路复用(一个 TCP 连接可以同时传输多个请求)
	 - 头部压缩
	 - 服务器推送
 - ==preconnect预连接==
	 - 提前建立 TCP 连接和进行 TLS 握手
**二.资源优化**

1.**资源压缩与精简**

- **JavaScript/CSS**：使用 Webpack、Vite 等构建工具进行代码压缩（Terser）、混淆

- **Gzip/Brotli 压缩**

**2.清除渲染阻塞资源**
CSS 和同步的 JS 会阻塞 HTML 的解析和渲染
- - 将所有 `<script>` 标签放在 `<body>` 底部。
- 使用 `defer` 或 `async` 属性异步加载非关键 JS。
3.**资源预加载**
