5.Flexbox 高频问题
**主轴与交叉轴​**​：Flexbox布局的核心。主轴方向由 `flex-direction`决定（默认为 `row`，水平方向），交叉轴则与主轴垂直 理解这一点是使用 `justify-content`和 `align-items`的基础。
- ​**​`flex: 1`到底是什么**: `flex: 1`等价于 `flex: 1 1 0%`​**​该项目可以根据剩余空间自由伸缩（增长因子为1，收缩因子为1），且它在分配多余空间前的基准尺寸为0​**​`flex`是 `flex-grow`、`flex-shrink`和 `flex-basis`的简写
- `flex: auto`：等价于 `1 1 auto ---项目根据内容大小分配空间 默认
- `flex: none`：等价于 `0 0 auto ---项目不伸缩，保持原有尺寸
- `flex: 200px`：等价于 `1 1 200wpx ---基准为200px，然后按比例伸缩
6.**圣杯布局（经典三栏布局）**
```css
.container {
  display: flex;
  flex-direction: column; /* 设置为垂直方向为主轴 */
  min-height: 100vh; /* 容器至少为视口高度 */
}
.header, .footer { height: 60px; }
.main { flex: 1; } /* 关键：中间部分占据所有剩余空间 */

```

10.清除浮动
- **空标签法​**：在浮动元素末尾添加空标签（如 `<div>`）并设置 `clear: both;`
- 给父元素添加 `::after`伪元素，并设置 `display: block; clear: both; content: '';`语义性好，无需冗余标签，
- BFC元素在计算高度时，会包含其内部的浮动元素，常用触发方式：`overflow: hidden`或 `overflow: auto`
- 定高发：直接给父元素设置一个固定的高度（`height`）|

11.BFC
**块级格式化上下文**
BFC是一个独立的布局环境，可以理解为一个容器，在这个容器中按照一定规则进行物品摆放，并且不会影响其它环境中的物品。
- 创建
	- 元素设置float÷none
	- 元素设置绝对定位
	- display： inline-block flex table-cell
	- overflow: hiden auto scroll
- **BFC的特点**
	- 两个容器的margin会重叠
	- BFC是独立的容器，容器内部元素不会影响外部元素
